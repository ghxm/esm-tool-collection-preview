Sensor Data Collection

Sensor data can be categorized into sensor log data, device status log data, and usage log data (Schödel & Mehl, 2024). Sensor log data can be described as data from physical sensors like microphones, light sensors, or thermometers. Device status log data refers to data on the device status like battery level, whether headphones are plugged in, or the location via GPS. Usage log data is data on the use of the device, like app usage, in-app content tracking, camera usage, screen state, or notifications.

Survey flow options

Survey flow options help control the order and display of survey questions based on participant answers or grouping variables. We distinguish these survey flow options:

  • Skip/display logic describes the possibility to skip/display additional questions based on participant answers. For example, a person reporting that they consume coffee daily might be asked how many cups of coffee they drink each day, while a person reporting that they don't drink coffee will not.
  • Piping describes the insertion of participant input into following questions. For example, a participant might report that their best friend's name is "David". In the following question, they might be asked since when they know David.
  • Termination logic sets a rule for when the survey should be terminated immediately. For example, when specific inclusion criteria are not met.
  • Branching (participant grouping) defines survey paths based on participant answers, primarly by setting values like a grouping variable in an experimental design, or even sensor data like geolocation.
  • Question Grouping organizes items in chunks to aid navigation.
To control survey flow and logic, the tool allows for {surveyflow}.
Assessment schedules
 Assessment schedule refers to the timing of self-reporting:
  • Self-reminded: Participants choose when to make an assessment, e.g. in a diary format.
  • Time-based: Participants are prompted to make an assessment based on date and time, e.g. every day at 6. pm.
  • Event-based: Participants are prompted to make an assessment based on events the phone records (via sensors), e.g. being asked to contextualize a detected geolocation.
  • Preference-based: Participants can set their own scheduling plan according to their preferences.
